统一路由（经网关） ​

GET/POST /api/v1/platform/{name}/{path}?query...

{name} 取值：netease kugou unm lyric meting。路径与 query 原样透传给对应平台服务。

网关原生聚合接口：/api/v1/search、/api/v1/lyric、/api/v1/match。
